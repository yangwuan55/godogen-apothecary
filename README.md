# 炼金药铺（The Alchemist's Apothecary）

一款完整的 2D 药铺模拟经营游戏，基于 **Bevy 0.19** 开发，由 **godogen** 流程（`publish.sh --engine bevy --agent prime`）生成。

你经营一间挣扎求生的小药铺：进货原料、服务排队的顾客、通过控制温度和搅拌熬制药剂，一步步积累声望，直到贵族与炼金公会登门造访。

## 核心循环

```
进货原料 -> 顾客下单 -> 熬制（温度 + 搅拌）-> 出货 -> 金币 + 声望
      ^                                          |
      +----- 解锁配方 / 升级店铺 <----------------+
```

- **每日循环**：一天固定时长（75 秒）；每卖出一瓶药获得金币与声望，每天结束时**需要交房租**。
- **声望解锁内容**：声望越高，解锁更高阶配方与更挑剔（也更富有）的顾客。
- **胜败条件**：每天结束时金币不足 => 破产；声望升到 10 级 => 通关。

## 操作（鼠标 + 键盘双通道）

所有关键操作都有按钮，鼠标点击即可完成；键盘按键与按钮等价（同一套输入通道）。

| 操作           | 鼠标                         | 键盘 |
|----------------|------------------------------|------|
| 开始游戏 / 接单 | 点「开门营业」/「接单」      | `Enter`（接单也可用 `E`）|
| 温度控制       | 按住「升温 / 降温」按钮      | 按住 `↑` / `↓`（或 `W` / `S`）|
| 搅拌           | 点「搅拌」                   | `Space` |
| 打开面板       | 点 HUD 的「市场 / 升级 / 配方书」| `Tab` 循环切换 |
| 购买材料       | 点原料行「购入」，`+` / `−` 调数量 | `1..0`、`-`、`=` 购入；`[` / `]` 调数量 |
| 购买升级       | 点升级卡片「升级」           | `1..4` |
| 暂停           | 点 HUD「暂停」               | `Esc` 或 `P` |
| 返回柜台       | 面板底部「返回柜台」按钮     | `Tab` |
| 日结算继续     | 点「继续营业」               | `Enter` / `Space` |

> 面板软暂停：打开市场 / 升级 / 配方书时，顾客与熬制会暂停计时（柜台时间冻结），关面板后继续，不会耽误当天生意。
> 暂停菜单：暂停后所有玩法冻结，可选择继续 / 回标题 / 退出。

## 游戏内容

- **12 种材料**，分 3 阶（曼德拉草根 … 深渊之盐）。
- **14 个配方**，分 3 阶（治愈药水 … 凤凰之泪），各有理想温度区间、熬制时间与搅拌要求。
- **7 类顾客**（农夫、孩童、商人、骑士、法师、贵族、炼金术士），预算、耐心与解锁阶位各不相同；头顶气泡显示订单与耐心。
- **4 项店铺升级**（坩埚、熔炉、货架、招牌），每项最高 3 级。
- **品质系统**：完美 / 良好 / 普通 / 劣质的药水收益不同，由温度把握与搅拌覆盖决定。
- **新手引导**：前几单会弹出不打断操作的提示横幅，并高亮对应按钮。

## 程序化美术与音频（无外部资源）

所有画面均由 Bevy 图元在运行时绘制，音效与 BGM 由代码合成 WAV（启用 `bevy/wav` 特性），无需任何外部素材：

| 元素     | 构成                                    |
|----------|-----------------------------------------|
| 店面     | 木墙、地板、按颜色分类的药瓶货架        |
| 柜台     | 木质柜台 + 合页台面 + 递药窗口          |
| 坩埚     | 铁锅、液面、漂浮的材料颜色、熬制气泡    |
| 顾客     | 身体、头、帽子（3 种样式），按职业配色  |
| 特效     | 气泡、星芒、失败烟尘、飘字（金币/品质） |
| UI 面板  | 圆角矩形、进度条（温度 + 熬制）、HUD    |
| 音频     | 点击 / 搅拌 / 出货 / 失败 / 烧焦 / 金币 + 8 秒五声音阶 BGM 循环 |

## 运行

```sh
# 需要 Rust stable（已在 1.97 验证）
cargo run --release
```

> 注意：请用 `cargo run` 启动（`Cargo.toml` 已设 `default-run`）。Bevy 0.19 通过 `CARGO_MANIFEST_DIR` 定位 `assets/` 目录，直接运行编译产物会找不到字体文件。

## 证明视频

`docs/proof.mp4`（16 秒，720p）由 autopilot 自动演示：标题 → 接单控温熬制 → 市场购料（含调数量）→ 升级 → 配方书 → 继续炼药 → 暂停（冻结验证）→ 日结算 → 第二天开始。重新生成：

```sh
cargo run --bin capture && ffmpeg -y -framerate 30 -i screenshots/result/frame%05d.png -c:v libx264 -pix_fmt yuv420p docs/proof.mp4
```

## 架构

```
src/lib.rs          App 装配（build_app 暴露插件定制点，供 capture 复用）
src/main.rs         普通窗口版入口
src/bin/capture.rs  离屏 30fps 录制 + autopilot（证明视频）
src/game/
  core.rs           插件装配、状态、标题/结束流程
  data.rs           材料、配方、顾客、升级、品质
  resources.rs      经济、库存、炼制、顾客、特效资源
  actions.rs        统一输入通道（键盘 + 鼠标 -> UiAction 消息）
  customers.rs      生成、排队、耐心、接单/出货、顾客气泡
  brewing.rs        温度/搅拌机制、品质评分、出货
  economy.rs        每日循环、房租、解锁门槛、胜负判定
  panels.rs         市场 / 升级 / 配方书 Tab 面板
  ui.rs             HUD、炼药面板、日结算、结束画面、暂停
  ui_kit.rs         调色板 + 按钮 / 卡片 / 徽章 / 进度条
  tutorial.rs       新手引导（提示横幅 + 目标按钮高亮）
  audio.rs          程序合成音效与 BGM
  visual.rs         程序化店面、坩埚、顾客精灵
  particles.rs      特效生成 + 飘字
```

由 **godogen** 发布流程构建（Prime Agent 布局：`AGENTS.md` + `.prime/agent/skills/asset-gen`）。
