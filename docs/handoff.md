## 三、现状审计（已确认的问题，你的工作必须覆盖）

以下都是**已从代码核实**的问题，不是猜测：

1. **完全没有鼠标支持**：全游戏没有 `Interaction` / `Button` / 鼠标点击。所有操作靠键盘数字键，玩家点击界面毫无反应——这是"功能不可用"的最大来源。**必须引入鼠标可点按钮**（开始游戏、接单、购买、升级、切面板、确认等）。
2. **顾客头顶气泡是空文本**：`customers.rs` 里订单气泡 `Text2d::new("")`，没有任何系统更新它——顾客完全不会"说话"。需要实现气泡内容（顾客要什么、等待中、离开）。
3. **购买数量无法调整**：`Inventory.restock_qty` 固定为 1，没有 UI 或按键调整批量购买数量。
4. **UI 全是纯文本列表**：市场/升级/配方书都是单行文本堆叠，无按钮、无图标、无价格高亮、无可用/禁用状态、无悬停提示。需要做成真正的可交互面板。
5. **无音效、无背景音乐**：全项目没有任何音频。
6. **无暂停**：无法暂停游戏。
7. **新手引导不足**：只有标题屏一段说明，游戏内没有逐步引导/目标提示。
8. **炼药面板简陋**：温度/进度只是两行色条；没有坩埚动态画面、没有数值刻度、没有"即将烧焦"预警反馈。
9. **顾客视觉反馈弱**：接单/出货/离开缺可视化过程（无动画状态机区分，无金币飘字的对准感）。
10. **结算/胜负画面纯文本**：没有统计图表、没有下一天目标、没有重开按钮（仍需键盘）。
11. **缺反馈音/缺操作提示的"兜底"**：任何无效操作（材料不足、金币不足、满级）应有明确的界面反馈，而不只是世界飘字。
12. **HUD 无图标**：纯文字，缺可辨识的货币/声望/时间图标与层次。

## 六、硬性约束与已验证技术要点（务必遵守，避免重踩坑）

以下来自本项目已验证经验（详细见 `.prime/agent/skills/godogen-runtime/SKILL.md`）：

1. **窗口版必须用 `cargo run` 启动**：Bevy 0.19 资产根按 `BEVY_ASSET_ROOT` → `CARGO_MANIFEST_DIR` → exe 目录解析；直接运行 exe 会找不到 `assets/`。
2. **中文字体**：用 `assets/fonts/NotoSansSC.ttf`（可变字体）；粗体用 `TextFont.weight = FontWeight::BOLD`。不要换回不含中文的字体。
3. **ICU4X**：`Cargo.toml` 里 `icu_segmenter = { version = "2.3.0", features = ["auto"] }` 必须保留，否则中文报 segmentation 错误（错误本身是日志噪音，不影响渲染，但会刷屏）。
4. **UI emoji 慎用**：Noto Sans SC 不含彩色 emoji，列表里用 emoji 会变豆腐块；用文字/色块代替。
5. **面板遮挡**：非活动 UI 面板必须 `Visibility::Hidden`（不能 `Inherited`），否则不透明面板全叠盖世界。
6. **capture autopilot**：`ScheduleRunner` 会 catch-up 导致同一截图帧多次 `app.update()`，autopilot 必须**按帧幂等**（已实现于 `AutopilotState.acted_on`，改 autopilot 时保持该机制）；`Time::<Fixed>::from_hz(30.0)` 与 30fps 同步。
7. **离屏 capture**：capture 相机需 `IsDefaultUiCamera`；`WindowCamera(false)` 保证单相机。
8. **按键驱动**：autopilot 与游戏输入均用 `PreUpdate.after(bevy::input::InputSystems)`；瞬时键每帧先 release 再 press。
